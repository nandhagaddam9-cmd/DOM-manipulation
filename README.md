# Hide and Seek DOM Game

Interactive browser game built using JavaScript DOM Manipulation concepts.

---

## Features

- Fun hide and seek gameplay
- Dynamic box movement
- Randomized positions
- Interactive UI
- Real-time user interaction
- Beginner-friendly game logic

---

## Technologies Used

- HTML
- CSS
- JavaScript
- DOM Manipulation

---

## How the Game Works

1. User clicks the screen
2. Hidden box changes position
3. "Here I Am!" box appears randomly
4. Player must quickly find and click the box
5. Score or interaction continues dynamically

---

## Concepts Used

- DOM Selection
- Event Listeners
- Dynamic Element Positioning
- CSS Styling
- JavaScript Functions
- User Interaction Handling
